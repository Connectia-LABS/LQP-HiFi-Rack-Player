# Code of conduct

## Expected behavior

- Be respectful and specific.
- Critique code and decisions, not people.
- Welcome questions from developers with different experience levels.
- Protect private information and credentials.
- Give credit for contributions and prior work.

## Unacceptable behavior

Harassment, discrimination, threats, deliberate humiliation, publication of private information, credential sharing, or repeated disruption are not acceptable.

## Enforcement

Repository maintainers may edit or remove content, close discussions, reject contributions, or restrict participation when necessary to protect the project and its contributors.
